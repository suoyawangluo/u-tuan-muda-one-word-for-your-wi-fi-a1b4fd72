One word for your Wi-Fi: **Ghosting** — home Wi-Fi that vanishes mid-conversation, like a bad date who stops replying. There for the hello, gone by the punchline, back again when nobody needs it.

## Run it

```sh
node main.ts
```

It writes `Ghosting` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), checks the 1–20 character gate, reads the file back and verifies its sha256.
